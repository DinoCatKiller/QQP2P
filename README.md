# QQP2P - 自动化P2P连接机器人

通过QQ机器人自动建立P2P连接，双方只需发送简单消息即可完成IP交换和连接。

## 自动化流程

```
用户A                          机器人A                        用户B                          机器人B
  |                                |                              |                                |
  |                                |                              |                                |
  |--@机器人 给我一个p2p--------->|                              |                                |
  |                                |--回复IP信息---------------->|                              |
  |                                |                              |--看到IP信息-------------------->|
  |                                |                              |                                |
  |                                |                              |                                |
  |--@机器人 请你跟我这样做------->|                              |                                |
  |                                |                              |                                |
  |                                |--回复"请告诉我你的IP"------->|                              |
  |                                |                              |--收到请求---------------------->|
  |                                |                              |                                |
  |                                |                              |                                |
  |<---@机器人 我的IP是 1.2.3.4--|                              |<---@机器人 我的IP是 5.6.7.8-----|
  |    :8080                      |                              |    :8080                      |
  |                                |                              |                                |
  |                                |--记录B的IP----------------->|                                |
  |                                |                              |                                |
  |                                |<--记录A的IP-----------------|                                |
  |                                |                              |                                |
  |                                |--自动连接B----------------->|                                |
  |                                |                              |--自动连接A--------------------->|
  |                                |                              |                                |
  |<--✅ P2P连接成功-------------|                              |<--✅ P2P连接成功-----------------|
  |                                |                              |                                |
```

## 使用方法

### 1. 启动机器人（两台设备都需要）

```bash
cargo run -- start --user-id 你的QQ号 --port 8080
```

### 2. 在QQ中操作

**步骤1：获取本机IP**
```
@机器人 给我一个p2p
```
机器人回复：
```
🌐 我的P2P节点信息:
📍 公网IP: xxx.xxx.xxx.xxx
🔌 端口: 8080

请把这个信息告诉对方
```

**步骤2：让对方也获取IP**
对方同样发送：
```
@机器人 给我一个p2p
```

**步骤3：交换IP**
把机器人回复的IP信息告诉对方（通过QQ私聊或其他方式）

**步骤4：建立连接**
双方分别发送对方的IP信息：
```
@机器人 我的IP是 xxx.xxx.xxx.xxx:8080
```

**步骤5：自动连接**
机器人自动记录对方IP并开始连接，双方都会收到：
```
✅ P2P连接成功!
📍 对方IP: xxx.xxx.xxx.xxx
🔗 连接已建立
```

## 命令速查

| 发送 | 效果 |
|------|------|
| `给我一个p2p` | 获取本机IP信息 |
| `请你跟我这样做` | 询问对方IP |
| `我的IP是 1.2.3.4:8080` | 记录对方IP并自动连接 |
| `/connect 1.2.3.4:8080` | 手动连接 |
| `/status` | 查看连接状态 |
| `/help` | 帮助信息 |

## 命令行工具

```bash
# 查询本机IP
cargo run -- ip --user-id 12345

# 查看连接状态
cargo run -- status --user-id 12345

# 手动连接
cargo run -- connect --target "1.2.3.4:8080" --user-id 12345

# 检查机器人状态
cargo run -- online

# 查看好友/群列表
cargo run -- friends
cargo run -- groups
```

## 项目结构

```
src/
├── main.rs    # CLI入口
├── napcat.rs  # NapCat API + P2P核心
└── app.rs     # 消息处理
```

## 注意事项

1. 两台设备都需要启动机器人
2. NapCat必须运行（默认 127.0.0.1:30000）
3. 防火墙需要允许TCP连接
4. 使用公网IP，内网穿透可能需要额外配置
